# VARUNA Development Guide — 02. Coding Standards & Inviolable Rules

---

## 1. Ten Non-Negotiable Architectural Invariants

1. **Zero-Local-LLM Invariant**: All primary generation flows through `openrouter_client.py` using `nvidia/nemotron-ultra-550b-a55b:free`. Ollama and HuggingFace in-process models are strictly prohibited in the production path.
2. **Zero-Startup-Blocking Invariant**: Never load heavyweight neural libraries (e.g. `SentenceTransformer("...")`) at server import time.
3. **Strict SQL Sanitization Invariant**: Every query generated by an LLM or sub-agent must pass through AST / regex sanitization ensuring `SELECT`-only semantics before reaching PostgreSQL.
4. **Data Provenance Invariant**: Every numerical claim in a synthesized answer must trace directly to a returned SQL row or biological occurrence ID.
5. **Discrete Spatial-Temporal Binning Invariant**: Cross-domain joins between physical ocean profiles and biological records must strictly enforce $\Delta r \le 50.0\,\text{km}$ and $\Delta t \le 7\,\text{days}$.
6. **No Secret Ingestion Invariant**: Never commit `.env` files or API keys. Always use `.env.example` templates.
7. **Rubric Modesty Invariant**: Never use banned claims ("first in the world", "unique", "100% accuracy") in prompts, answers, or documentation.
8. **TypeScript Strict Mode Invariant**: `tsconfig.json` enforces `"strict": true`. Zero usage of `any` or `@ts-ignore` without explicit lead review.
9. **Liquid Glass Identity Invariant**: Maintain `.glass` and `.glass-strong` custom properties. Never introduce generic purple/violet AI glow blobs.
10. **Async Non-Blocking I/O Invariant**: All network calls, database transactions, and file I/O in FastAPI must be strictly `async/await` enabled.
